Комплексний аналітичний та інженерний проєкт з дослідження просторово-часових закономірностей оголошення повітряних тривог в Україні (з 15 березня 2022 по 5 вересня 2026 року) на основі офіційних верифікованих даних.

Проєкт поєднує **описову аналітику часових рядів (EDA, RQ1–RQ3)** та **систему каузального машинного навчання (ML)** для короткострокового прогнозування початку нової тривоги у періоди відносного спокою ($T \to T+1$ год).

> **Верифікація джерела даних:**  
> Дані завантажено з офіційного архіву [Vadimkin/ukrainian-air-raid-sirens-dataset](https://github.com/Vadimkin/ukrainian-air-raid-sirens-dataset) (коміт від 08.09.2026).

## 🔬 Ключові результати дослідницького аналізу (RQ1–RQ3)

### 1. Часова циклічність (RQ1)
* **Тижневий ритм (тест Краскела-Волліса):** $H = 13.72, \ p = 0.033$. Відмінності між днями тижня є статистично значущими. Пік активності припадає на середу–п'ятницю (медіана 92–94 тривоги/добу), тоді як мінімум фіксується в неділю (78 тривог/добу, спад на $-15\%$).
* **Трансформація атак (еволюція 2022 ➔ 2026):** Якщо у 2022 році домінувала денна активність (09:00–19:00), то у 2024–2026 роках через масовані нічні удари БПЛА «Shahed» сформувалося стале нічне плато (00:00–05:00). Частка нічних тривог зросла з **$20.2\%$ до $30.7\%$**.
* **Тривалість тривог:** Медіана тривалості становить **40.4 хвилини**, тоді як середнє арифметичне — **79.7 хвилин** (важкий правий хвіст через тривалі загрози стратегічної авіації).

### 2. Регіональні кластери небезпеки (RQ2)
Ієрархічна агломеративна кластеризація (Ward linkage, евклідова відстань на стандартизованих 5 метриках навантаження, коефіцієнт силуету = 0.385) виділила 3 природні макрозони України:
* **Кластер 1 (Глибокий тил, 11 областей):** Захід України + Житомирська, Київська, Вінницька. Середнє навантаження — 38.4 тривог/місяць.
* **Кластер 2 (Транзитний центр / Північ, 11 областей):** Центр, Північ, Південь та м. Київ. Середнє навантаження — 144.9 тривог/місяць; переважають короткі тривоги ($\le 30$ хв) балістичного характеру.
* **Кластер 3 (Фронтова зона, 2 області):** Донецька та Сумська. Середнє навантаження — 203.8 тривог/місяць; понад 30% тривог тривають понад 2 години через регулярну роботу тактичної авіації та КАБів.

* З аналізу вилучено понад 1 000 годин синхронних загальнонаціональних тривог ($\ge 15$ областей одночасно при зльотах МіГ-31К), що дозволило позбутися артефактних нульових затримок.

## 🤖 Машинне навчання: Прогнозування початку тривоги

### Постановка задачі
* **Кондиціонування на спокій:** Прогноз формується виключно в момент, коли сирена в області не активна (`is_active_T == 0`).
* **Ціль:** Передбачити, чи почнеться нова тривога у наступне годинне вікно $(T, T+1\text{h}]$: $y_T = 1$.
* **Ознаки:** Всі фактори обчислюються суворо каузально за вікнами $[T-k, T]$, закритими зліва (`closed='left'`).
* **Кластеризація в ML:** Щоб уникнути витоку майбутнього, для ML-ознак кластеризацію перераховано **виключно на вибірці Train (2022–2024)** (`reports/clusters_train_only.csv`).

## 💡 Інтерпретація результатів: Як працює прогноз

1. **Фоновий ризик проти прогнозованого:**
   У випадковий спокійний час імовірність раптового початку тривоги в будь-якій області становить усього **~2.2–2.4%** (сильний дисбаланс 1:40). Коли ситуація безпечна, модель тримає оцінку на рівні $0.5\% – 1.5\%$.
2. **Сплеск небезпеки:**
   Коли починається нічна атака або сирени лунають у суміжних прикордонних регіонах, модель підвищує розрахункову ймовірність для транзитних областей до **$15\% – 35\%+$**.
3. **Операційний поріг $p^* = 0.105$ (10.5%):**
   У завданнях оповіщення про небезпеку пріоритетом є максимальне виявлення загрози ($Recall$, оптимізація $F_2$-метрики):
   * Модель ловить **68.5% (майже 7 із 10)** усіх нових несподіваних тривог у наступну годину.
   * Серед усіх виданих попереджень точність складає **13.8%**, що майже **у 6 разів перевищує фоновий ризик (2.2%)**. Тобто коли спрацьовує прапорець небезпеки — реальна загроза зростає у 6 разів.
4. **Калібрування ймовірностей:**
   Brier Score становить **0.0203**, що свідчить про високу каліброваність оцінок ризику (Reliability Curve).

## 🛰️ Ablation Study: Вплив просторових зв'язків

Дослідження ізольованого впливу просторових ознак (активність у сусідніх областях за останні 1, 3, 6 годин та кластери активності):
* **Для градієнтного бустингу (LightGBM):**  
  Просторові лаги забезпечують статистично достовірне підвищення якості: **PR-AUC зростає з 0.2135 до 0.2378** ($+11.4\%$ відносного зростання; 95% довірчі інтервали $[0.207, 0.220]$ та $[0.231, 0.245]$ не перетинаються).
* **Для лінійної моделі (LogReg):**  
  PR-AUC практично не змінюється ($0.2219 \to 0.2215$), проте наявність просторових зв'язків дозволяє обрати стабільніший поріг відсікання.
* **Висновок:** Поширення повітряних загроз між областями України має **виражений нелінійний, інтерактивний характер**, який ефективно вловлюють ансамблі дерев рішень.

#### Топ-фактори впливу на прогноз:
1. `burden_last_24h` (Gain 95.7k) — загальне навантаження тривогами за минулу добу.
2. `cluster_3_high_activity` (Gain 72.7k) — приналежність області до східно-південного кластера високої інтенсивності.
3. `neighbors_active_count` (Gain 32.1k) — кількість безпосередньо суміжних областей, де на момент $T$ уже звучить сирена (перевершує фактор години доби!).

## 🛡️ Захист від витоку даних (Zero Data Leakage)

Надійність результатів гарантується багаторівневою інженерною ізоляцією:
1. **Строгий хронологічний спліт:**
   * **Train (47.9%):** 15.03.2022 – 30.04.2024 (410,150 записів).
   * **Validation (22.2%):** 01.05.2024 – 31.05.2025 (190,195 записів).
   * **Test (29.8%):** 01.06.2025 – 05.09.2026 (254,830 записів).
2. **2-годинний буфер Embargo:** Видалено спостереження на межах періодів, щоб унеможливити перетин цільового вікна з тестовими даними.
3. **Ізоляція кластеризації:** Кластери для ML розраховані суворо на Train (`reports/clusters_train_only.csv`).
4. **Кондиціонування на спокій:** Моделювання ведеться лише для годин тиші (`is_active_T == 0`).
5. **Каузальний статус тривоги:** Відмова від використання прапорця `is_finished` (жодних знань про момент завершення поточної тривоги).
6. **Автоматизований тест інваріантності (`tests/test_leakage_invariance.py`):**  
   Для випадкових зрізів часу $T$ сирі дані фізично обрізаються по момент $T$, після чого ознаки перераховуються «наживо» і порівнюються з Feature Store. Тест підтверджує 100% числову ідентичність.

## 🚀 Швидкий старт (Quickstart)

### 1. Клонування та налаштування оточення
```bash
git clone https://github.com/Yaroo-a/ukrainian-air-raid-sirens-analysis.git
cd ukrainian-air-raid-sirens-analysis
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2. Запуск дослідницьких блокнотів
```bash
jupyter lab
```
* `notebooks/01_data_profiling_and_cleaning.ipynb` — валідація, типізація та очищення сирих даних.
* `notebooks/02_rq1_temporal_cyclicity.ipynb` — аналіз тижневих/добових ритмів та Kruskal-Wallis.
* `notebooks/03_rq2_regional_clustering.ipynb` — регіональні паспорти безпеки та кластеризація.
* `notebooks/04_rq3_spatial_propagation_routes.ipynb` — lead-lag затримки між сусідами.
* `notebooks/05_ml_forecasting_experiment.ipynb` — повний цикл ML: Feature Store, навчання, абляція та графіки.

### 3. Запуск автоматизованого пайплайну
```bash
# Перевірка відсутності витоку даних
python tests/test_leakage_invariance.py

# Генерація ознак, навчання моделей та фінальне тестування
python src/features/feature_store.py
python src/models/baselines.py
python src/models/train_models.py
python src/models/evaluate_test.py
```
