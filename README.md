# 🚨 Аналіз та прогнозування повітряних тривог в Україні (2022–2026)

[![Python 3.14](https://img.shields.io/badge/Python-3.14-blue.svg)](https://www.python.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Data](https://img.shields.io/badge/Dataset-130k%20Alerts-red.svg)](https://github.com/Vadimkin/ukrainian-air-raid-sirens-dataset)
[![Storage](https://img.shields.io/badge/Storage-Apache%20Parquet-green.svg)](https://parquet.apache.org/)
[![ML](https://img.shields.io/badge/Model-LightGBM%20%7C%20LogReg-orange.svg)](reports/ml_models_benchmark.csv)

Комплексне Data Science дослідження просторово-часових закономірностей повітряних тривог в Україні за понад 4.5 роки (15.03.2022 – 05.09.2026) на основі офіційних верифікованих даних (130 000+ подій у 24 регіонах).

Проєкт поєднує **глибоку описову аналітику (EDA)** та **машинне навчання (ML)** для короткострокового прогнозування загрози на наступну годину ($T \to T+1$ год) у періоди спокою з абсолютним математичним захистом від витоку даних.

---

## 🔬 Головні наукові результати

### 1. Часова циклічність (RQ1)
* **Тижневий ритм (Kruskal-Wallis тест):** $H = 13.72, \ p = 0.033$. Відмінності між днями тижня є статистично значущими. Пік ударів — середа–п'ятниця (медіана 92–94 тр/добу), спад — неділя (78 тр/добу, -15%).
* **Зсув на нічні атаки:** У 2022 році тривоги переважали вдень (09:00–19:00). У 2024–2026 роках через масовані нальоти БПЛА сформувалося стабільне нічне плато (00:00–05:00), а частка нічних тривог зросла з **$20.2\%$ до $30.7\%$**.
* **Тривалість:** Медіана тривалості становить **40.4 хв**, тоді як середнє — **79.7 хв** (важкий правий хвіст через багатогодинні комбіновані атаки).

### 2. Географічні кластери безпеки (RQ2)
Ієрархічна кластеризація (Ward, Silhouette Score = 0.385) розділила Україну на 3 природні зони:
* **Кластер 1 (Глибокий тил, 11 областей):** Західні регіони + Житомирська, Київська, Вінницька. Сер. частота — **38.4 тр/міс**. Найвища частка нічних тривог (26.4%). Закарпаття мало лише 1 326 тривог за весь час.
* **Кластер 2 (Транзитний центр / Північ, 11 областей):** Центр, Північ, Південь та м. Київ. Сер. частота — **144.9 тр/міс**. Найвища частка коротких тривог $\le 30$ хв (36.2%) через зльоти МіГ-31К та балістику.
* **Кластер 3 (Фронт, 2 області):** Донецька та Сумська. Сер. частота — **203.8 тр/міс**. Понад 30% тривог тривають довше 2 годин.

### 3. Маршрути загроз та затримки (RQ3)
* Ізольовано понад 1 000 годин синхронних загальнонаціональних тривог ($\ge 15$ областей), щоб уникнути хибних миттєвих нульових затримок.
* На основі 49 пар суходільних кордонів виявлено стабільні маршрути поширення небезпеки із затримкою підльоту в **10–20 хвилин** (наприклад, Хмельницька ➔ Вінницька $r=0.45$, Черкаська ➔ Кіровоградська $r=0.60$).

### 4. Прогнозування та змагання моделей (Machine Learning)
**Постановка задачі:** Прогноз робиться строго в моменти спокою, коли на позначці $T$ тривоги немає. Модель оцінює ймовірність того, що нова тривога розпочнеться протягом наступних 60 хвилин ($T < \text{started\_at} \le T+1\text{h}$).

| Модель | Конфігурація | Test $F_2$-Score | Test PR-AUC | Test Precision | Test Recall | Lift над Baseline ($F_2$) |
| :--- | :--- | :---: | :---: | :---: | :---: | :---: |
| **Baseline 1: Naive Persistence** | Попередній лаг старту | $0.2041$ | — | $20.4\%$ | $20.4\%$ | $+43.4\%$ |
| **Baseline 2: Historical Lookup** | Статична таблиця Train | $0.1423$ | $0.0329$ | $3.5\%$ | $64.1\%$ | **База (0%)** |
| **Logistic Regression (With Spatial)** | Час + Пам'ять + Сусіди | **$0.4000$** | **$0.2215$** | **$16.7\%$** | **$61.5\%$** | **$+181.1\%$** |
| **LightGBM (With Spatial)** | Час + Пам'ять + Сусіди | **$0.3823$** | **$0.2378$** | **$13.8\%$** | **$68.5\%$** | **$+168.6\%$** |

#### Наукові висновки:
1. **Стійкість проти зсуву розподілу (Concept Drift):** На тесті (2025–2026) фонова частота стартів тривог у спокійні години впала з 8.1% до 2.21%. Статична таблиця шансів зазнала краху ($F_2=0.14$, Precision впав до 3.5%), тоді як ML-моделі показали **Lift $+168\dots+181\%$ по $F_2$ та понад $+600\%$ по PR-AUC**.
2. **Внесок просторових лагів (Ablation Study):** Додавання статусів сусідів більш ніж подвоїло Precision логістичної регресії (з 6.9% до 16.7%) та збільшило $F_2$ з 0.24 до 0.40.
3. **Фактор №1 за Gain у LightGBM:** Найсильніший предиктор — добовий темп атак (`burden_last_24h`, Gain 95.7k), за ним — прифронтова зона (`cluster_3_front`, Gain 72.7k) та кількість активних сусідів (`neighbors_active_count`, Gain 32.1k).

## 🛡️ Суворий захист від витоку даних (Zero Data Leakage)

1. **Кондиціонування на періоди спокою:** Прогноз виконується виключно тоді, коли тривога на момент $T$ вимкнена. З вибірки вилучено періоди активних сирен, запобігаючи тривіальним прогнозам.
2. **Кластеризація суворо на Train:** Регіональні кластери для ML (`reports/clusters_train_only.csv`) розраховані виключно за даними Train (до 30.04.2024), без залучення Val чи Test.
3. **Хронологічний спліт з Embargo (2 години):**
   * **Train (47.9%):** 15.03.2022 – 30.04.2024 (410,150 рядків).
   * **Validation (22.2%):** 01.05.2024 – 31.05.2025 (190,195 рядків).
   * **Test (29.8%):** 01.06.2025 – 05.09.2026 (254,830 рядків).
4. **Суто казуальні вікна:** Усі показники навантаження (`burden_last_6h`, `burden_last_24h`) розраховані з `closed="left"` строго до моменту $T$.
5. **Жодного знання про майбутнє завершення тривог:** Вибірка не фільтрується штучним прапорцем `is_finished`, статус розраховується казуально.
6. **Frozen Thresholds:** Оптимальний поріг $p^*$ для максимізації $F_2$ підібрано **виключно на Validation** і без змін перенесено на Test.

## 🚀 Швидкий старт (Quickstart)

### 1. Клонування та налаштування
```bash
git clone https://github.com/Yaroo-a/ukrainian-air-raid-sirens-analysis.git
cd ukrainian-air-raid-sirens-analysis
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2. Дослідницькі Jupyter Notebooks
```bash
jupyter lab
```
Усі етапи структуровано за блокнотами в папці `notebooks/`:
* `01_data_profiling_and_cleaning.ipynb` — валідація, типізація та очищення сирих даних.
* `02_rq1_temporal_cyclicity.ipynb` — добова/тижнева циклічність та Kruskal-Wallis.
* `03_rq2_regional_clustering.ipynb` — цифрові паспорти регіонів та кластеризація.
* `04_rq3_spatial_propagation_routes.ipynb` — просторово-часові затримки між областями.
* `05_ml_forecasting_experiment.ipynb` — Feature Store, бейзлайни, змагання ML та Feature Importance.

### 3. Автоматизований запуск пайплайну
```bash
# Тест цілісності аналітики
python tests/verify_pipeline.py

# Генерація ознак, навчання моделей та фінальне тестування
python src/features/feature_store.py
python src/models/baselines.py
python src/models/train_models.py
python src/models/evaluate_test.py
```
