Науково-дослідницький проєкт з аналізу просторово-часових закономірностей оголошення повітряних тривог в Україні (з 15 березня 2022 по 5 вересня 2026 року) на основі офіційних верифікованих даних.

Проєкт поєднує **описову аналітику часових рядів (EDA, RQ1–RQ3)** та **машинне навчання (ML)** для прогнозування початку нової тривоги у періоди тиші ($T \to T+1$ год).

> **Верифікація джерела даних:**  
> Дані завантажено з офіційного архіву [Vadimkin/ukrainian-air-raid-sirens-dataset](https://github.com/Vadimkin/ukrainian-air-raid-sirens-dataset) (останній upstream коміт від 08.09.2026).  
> Хеш-сума сирого файлу `data/raw/official_data_uk.csv`:  
> `SHA-256: 1f50085481d229f57b624d83b1ce723e884dea409c14afb5b7040c8a2f233e4f` (Git blob: `71d70c0ca54968f530d596cf315616fa858800e1`).

## 🔬 Ключові результати дослідження

### 1. Часова циклічність (RQ1)
* **Тижневий ритм (Kruskal-Wallis тест):** $H = 13.72, \ p = 0.033$. Відмінності між днями тижня є статистично значущими. Пік активності — середа–п'ятниця (медіана 92–94 тр/добу), спад — неділя (78 тр/добу, -15%).
* **Трансформація в нічні атаки:** У 2022 році переважала денна активність (09:00–19:00). У 2024–2026 роках через систематичні нальоти БПЛА сформувалося нічне плато (00:00–05:00), а частка нічних тривог зросла з **$20.2\%$ до $30.7\%$**.
* **Тривалість:** Медіана тривалості становить **40.4 хв**, тоді як середнє — **79.7 хв** (важкий правий хвіст через масовані удари).

### 2. Географічні кластери безпеки (RQ2)
Ієрархічна кластеризація за всіма 4.5 роками (Ward, Silhouette = 0.385) виділила 3 регіональні зони:
* **Кластер 1 (Глибокий тил, 11 областей):** Західні регіони + Житомирська, Київська, Вінницька (сер. 38.4 тр/міс).
* **Кластер 2 (Транзитний центр / Північ, 11 областей):** Центр, Північ, Південь та м. Київ (сер. 144.9 тр/міс, висока частка тривог $\le 30$ хв через балістику).
* **Кластер 3 (Фронт, 2 області):** Донецька та Сумська (сер. 203.8 тр/міс, понад 30% тривог тривають понад 2 години).

### 3. Просторово-часові маршрути загроз (RQ3)
* Ізольовано понад 1 000 годин синхронних загальнонаціональних тривог ($\ge 15$ областей), щоб уникнути хибних миттєвих нульових затримок.
* На основі 49 пар суміжних областей зафіксовано затримки підльоту в **10–20 хвилин** на типових транзитних коридорах (Хмельницька ➔ Вінницька $r=0.45$, Черкаська ➔ Кіровоградська $r=0.60$).

## 🤖 Етап 2: Прогнозування початку тривоги (Machine Learning)

### Постановка задачі
Прогноз робиться в моменти спокою: на точці $T$ сирена не звучить (`is_active_T == 0`).  
Модель оцінює ймовірність початку нової тривоги протягом наступних 60 хвилин: $y_T = 1$, якщо нова тривога починається в інтервалі $(T, T+1\text{h}]$.

> **Важливе методологічне розмежування кластерів:**  
> Щоб уникнути витоку даних, у ML-моделях використовуються кластери, розраховані **виключно на Train-періоді (2022–2024)**:  
> `cluster_1_low_activity` (Тил, 7 обл.), `cluster_2_medium_activity` (Центр, 5 обл.), `cluster_3_high_activity` (Зона високої активності: фронт + схід/південь, 12 обл.).

### Фінальний бенчмарк на тестовій вибірці (Test: червень 2025 – вересень 2026)
*Всього 254 830 спокійних годин, 5 631 стартів тривог (базова частота 2.21%).*

| Модель | Тип ознак | Поріг $p^*$ (з Val) | Test PR-AUC [95% CI] | Test $F_2$-Score [95% CI] | Precision | Recall | Brier Score |
| :--- | :--- | :---: | :---: | :---: | :---: | :---: | :---: |
| **Baseline 1: True Naive Persistence** | Лаг старту о $T-1$ | 0.500 | — | 0.0686 | 18.3% | 5.9% | 0.0267 |
| **Baseline 2: Historical Lookup Table** | Таблиця шансів Train | 0.085 | 0.0334 [0.031, 0.036] | 0.1421 [0.140, 0.146] | 3.4% | 67.7% | 0.0273 |
| **Baseline 3: Adaptive 14-day Rolling** | Адаптивна частота 14 днів | 0.089 | 0.2205 [0.214, 0.227] | **0.4001** [0.390, 0.407] | 17.7% | 58.4% | **0.0189** |
| **LogReg (No Spatial)** | A: Час + Темп | 0.521 | 0.2219 [0.215, 0.228] | 0.2423 [0.239, 0.248] | 6.9% | 65.7% | 0.1734 |
| **LogReg (With Spatial)** | B: Час + Темп + Сусіди | 0.572 | 0.2215 [0.215, 0.228] | 0.4000 [0.392, 0.407] | 16.7% | 61.5% | 0.1612 |
| **LightGBM (No Spatial)** | A: Час + Темп | 0.093 | 0.2135 [0.207, 0.220] | 0.3354 [0.329, 0.342] | 11.6% | 63.3% | 0.0208 |
| **LightGBM (With Spatial)** | B: Час + Темп + Сусіди | 0.105 | **0.2378** [0.231, 0.245] | 0.3823 [0.375, 0.390] | 13.8% | **68.5%** | 0.0203 |

### Чесні наукові висновки з бенчмарку:
1. **Ефект Concept Drift та стійкість бейзлайнів:**  
   * Статична таблиця ймовірностей Historical Lookup обвалилася на тестовому періоді через падіння частоти тривог з 8.1% до 2.21% (Precision лише 3.4%).
   * Адаптивний бейзлайн (Baseline 3), що відстежує локальну частоту за останні 14 днів, виявився сильним конкурентом ($F_2 = 0.4001$).
2. **Статистично доведений внесок просторових лагів (Ablation Study):**  
   * Для **LightGBM** додавання лагів суміжних регіонів забезпечило достовірне зростання **PR-AUC з 0.2135 до 0.2378** (95% довірчі інтервали [0.207, 0.220] та [0.231, 0.245] не перетинаються!).
   * Для **Logistic Regression** додавання просторових ознак підвищило робочий поріг оптимізації $F_2$, що підняло точність (Precision) з 6.9% до 16.7% при збереженні PR-AUC на рівні 0.221.
3. **Фактори впливу (Feature Importance за Gain у LightGBM):**  
   * **1-е місце:** Добовий темп атак (`burden_last_24h`, Gain 95.7k).
   * **2-е місце:** Кластер високої активності (`cluster_3_high_activity`, Gain 72.7k).
   * **3-є місце:** Кількість активних сусідів на момент $T$ (`neighbors_active_count`, Gain 32.1k), що випереджає сезонність, години та дні тижня.
4. **Оцінка на найсвіжішому періоді (останні 60 днів):**  
   * На останніх 60 днях спостерігалося екстремальне затишшя (лише 141 тривога на 34,442 годин спокою, частота 0.41%). В таких умовах статичні пороги класифікації видають завищену кількість хибних тривог, що підкреслює потребу динамічного threshold-moving в онлайні.

## 🛡️ Верифікація відсутності витоку даних

Захист від Data Leakage реалізовано через конкретні інженерні протоколи:
1. **Строгий хронологічний спліт:**
   * **Train (47.9%):** 15.03.2022 – 30.04.2024 (410,150 рядків).
   * **Validation (22.2%):** 01.05.2024 – 31.05.2025 (190,195 рядків).
   * **Test (29.8%):** 01.06.2025 – 05.09.2026 (254,830 рядків).
2. **2-годинний буфер Embargo:** Видалено години на стиках вибірок, щоб цільове вікно $(T, T+1\text{h}]$ не перетинало кордон сплітів.
3. **Train-Only кластеризація:** Розрахована виключно за даними Train до 30.04.2024 (`reports/clusters_train_only.csv`).
4. **Кондиціонування на тишу:** Моделі навчаються і тестуються виключно на спостереженнях, де сирена на момент $T$ вимкнена.
5. **Казуальний розрахунок статусу:** Без використання штучного прапорця `is_finished` (жодного знання про майбутній час завершення тривог).
6. **Автоматизований тест інваріантності (`tests/test_leakage_invariance.py`):**  
   Для випадкових точок $T$ сирі дані фізично обрізаються по момент $T$ (майбутнє повністю видаляється), після чого ознаки перераховуються з нуля і звіряються з Feature Store. Тест підтверджує 100% тотожність.

## 🚀 Швидкий старт (Quickstart)

### 1. Встановлення
```bash
git clone https://github.com/Yaroo-a/ukrainian-air-raid-sirens-analysis.git
cd ukrainian-air-raid-sirens-analysis
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2. Запуск Jupyter Notebooks
```bash
jupyter lab
```
* `01_data_profiling_and_cleaning.ipynb` — валідація, типізація та очищення сирих даних.
* `02_rq1_temporal_cyclicity.ipynb` — аналіз тижневих/добових ритмів та Kruskal-Wallis.
* `03_rq2_regional_clustering.ipynb` — регіональні паспорти та кластеризація областей.
* `04_rq3_spatial_propagation_routes.ipynb` — lead-lag аналіз затримок між сусідами.
* `05_ml_forecasting_experiment.ipynb` — повний цикл ML: Feature Store, бейзлайни, змагання та важливість ознак.

### 3. Автоматизований пайплайн та тести
```bash
# Автотест відсутності витоку даних
python tests/test_leakage_invariance.py

# Генерація ознак, навчання моделей та фінальне тестування
python src/features/feature_store.py
python src/models/baselines.py
python src/models/train_models.py
python src/models/evaluate_test.py
```
